# Minishell

Este projeto da 42 é a implementação de um shell minimalista em C, capaz de interpretar e executar comandos como um terminal UNIX. Ele suporta redirecionamentos, pipes, variáveis de ambiente, sinais, comandos built-in e execução de binários. O objetivo é entender como funciona um shell por trás dos panos, reforçando conceitos de parsing, fork, execve e gerenciamento de processos.
